# 무료 AI 전화 접수 PoC

PC에서 질문 안내·업무 요청 접수·분류·요약을 시험하는 Windows 앱입니다. 유료 API 키나 전화망 가입 없이 Ollama의 qwen3:1.7b를 사용합니다.

## 집 PC에서 시작

Windows x64, [Node.js 22 이상](https://nodejs.org/), [Git](https://git-scm.com/downloads), Chrome 또는 Edge가 필요합니다. 최초 설치에는 인터넷과 수 GB의 디스크 공간이 필요합니다.

아래 명령은 PowerShell용입니다. 새 폴더에 복제하므로 같은 이름의 기존 폴더가 있으면 다른 경로를 사용하세요.

~~~powershell
# 원격 소스를 새 로컬 폴더로 복제합니다. GitHub 파일은 변경하지 않습니다.
git clone https://github.com/codingfeedback/call_custmor_center.git
# 복제한 작업 폴더로 이동합니다.
Set-Location .\call_custmor_center
# 앱을 시작합니다. 최초 실행은 공식 Ollama 배포본과 무료 모델을 내려받습니다.
.\시작.cmd
~~~

시작.cmd는 PowerShell 스크립트 실행 정책을 해당 프로세스에서만 Bypass로 지정합니다. 시스템 정책은 변경하지 않습니다. setup.ps1은 공식 Ollama Windows ZIP을 runtime 폴더에 설치하며, 이미 실행 파일이 있으면 재사용합니다. 모델·다운로드·로그는 runtime에 보관하고 Git에 포함하지 않습니다. Node.js와 Git은 자동 설치하지 않습니다.

브라우저에서 http://127.0.0.1:8765/ 를 엽니다. 음성은 Chrome/Edge에서 시험하세요. 인앱 브라우저에서는 STT가 시작되지 않는 현상이 확인됐습니다.

- 텍스트: AI 답변 읽어주기를 끄고 입력 후 보내기.
- 음성: 음성 대화 시작 → 마이크 권한 허용 → 말이 끝나면 자동 전송 → AI 답변 후 다시 듣기.
- 중지: 음성 대화 중지. 종료·최종 요약 후에도 새 음성 접수로 다시 시작할 수 있습니다.
- 결과: 화면에서 확인하거나 JSON 저장. 자동 파일 저장은 없으며 새 접수·새로고침은 화면의 대화를 지웁니다.
- 앱 종료: 중지.cmd. 이 폴더에서 시작한 프로세스만 종료하며 별도로 실행된 Ollama는 유지합니다.

## FAQ 등록

faq.json에 다음 형식의 항목을 추가합니다. id는 고유해야 합니다. aliases는 선택 사항입니다.

~~~json
{
  "id": "opening_hours",
  "question": "영업시간이 어떻게 되나요?",
  "answer": "여기에 실제 안내할 영업시간을 입력하세요.",
  "aliases": ["몇 시까지 영업해요?", "문 여는 시간이 언제예요?"]
}
~~~

저장 후 다음 요청부터 반영되며 서버 재시작이 필요 없습니다. 등록 질문·aliases의 정확한 일치는 직접 답하고, 다른 표현은 관련 후보 안에서 모델이 고릅니다. 정보가 없으면 미등록 안내를 합니다. 표현이 크게 다르면 놓칠 수 있으니 시험한 표현을 aliases에 추가하세요. 현재 FAQ는 PoC 기능·비용·전화 연결 가능 여부에 관한 샘플입니다.

업무 요청은 대상·처리 내용·오류 상황 중 필요한 정보 하나를 묻습니다. 모든 요청에 기한을 요구하지 않으며, 연락처도 묻지 않습니다. PC 버전은 발신번호를 수집하지 않습니다.

## 검증

앱 서버가 8765 포트를 사용하므로 test.mjs 실행 전에 중지.cmd로 앱을 종료하세요. test-voice.mjs는 모의 이벤트 검증이며 실제 마이크 시험은 아닙니다.

~~~powershell
# 앱을 중지합니다. 이 작업 폴더에서 실행한 앱·Ollama 프로세스를 종료합니다.
.\중지.cmd
# 입력·FAQ·결과 검증과 로컬 HTTP 접근 검사를 실행합니다.
node test.mjs
# 자동 전송·음성 재생 대기·재청취·중지·STT 시작 실패 처리를 모의 이벤트로 검사합니다.
node test-voice.mjs
# 앱과 모델을 다시 시작합니다.
.\시작.cmd
# 실제 로컬 모델로 질문·요청·연속 대화·FAQ 즉시 반영 시나리오를 검사합니다.
node verify-scenarios.mjs
~~~

verify-scenarios.mjs는 FAQ에 테스트 항목을 잠시 추가하고 검사 후 원문을 복원합니다. 검사 중에는 FAQ를 편집하지 마세요. 도중 사용자 수정이 발견되면 덮어쓰지 않고 실패합니다. 생성되는 검증 결과 JSON은 Git에서 제외됩니다.

## 다른 PC와 작업 이어가기

작업을 마친 PC에서 소스를 커밋·푸시하고, 다른 PC에서 변경을 받습니다. FAQ도 Git으로 공유되므로 실제 고객 정보나 비밀을 넣지 마세요. 모델·로그·화면 캡처·대화 결과는 동기화하지 않습니다.

~~~powershell
# 원격 변경을 직선 이력일 때만 반영합니다. 자동 병합하지 않으며 로컬 변경과 충돌하면 중단합니다.
git pull --ff-only
~~~

## 구성과 제한

- server.mjs: 로컬 HTTP 서버, Ollama 호출, FAQ 선택, 요청 분류·요약.
- index.html: 텍스트·음성 대화와 접수 결과 화면.
- faq.json: 안내 정보와 같은 질문의 다른 표현.
- setup.ps1 / start.ps1 / stop.ps1: Windows 설치·시작·종료.
- 로컬 주소: 앱 127.0.0.1:8765, Ollama 127.0.0.1:11434.

브라우저 STT는 외부 인식 서비스를 사용할 수 있습니다. 완전한 오프라인 구성이 아니며 가상 정보로 시험하세요. AI 분류·정보 추출은 PC에서 처리하고, 음성 출력은 브라우저 음성 합성을 사용합니다. AI 답변 중 끼어들기는 지원하지 않습니다. 소형 모델은 오분류·요약 누락이 가능하므로 결과를 확인하세요.

실제 전화 수신·담당자 연결·SMS·업무 처리는 구현하지 않았습니다. 안내 정보는 FAQ 등록으로 바꿀 수 있지만 실제 처리·연결에는 별도 연동이 필요합니다. 집 PC의 장치·마이크·깨끗한 환경에서의 최초 다운로드는 현 PC 검증과 별개입니다.

## 실제 전화 수신 준비

번호 발급 전 SIP 소프트폰 내선 테스트와 무료 로컬 STT·TTS 구성은 [phone/README.md](phone/README.md)를 참고하세요. Asterisk + faster-whisper + eSpeak NG를 사용하며 기존 웹 테스트와 별도로 실행합니다. 기본은 loopback 수신 전용이고, 통신사 번호·IP 설정 및 실제 전화망 검증은 별도로 필요합니다.

ClawOps WebSocket 연결(번호 없는 모의 검증, 로컬 AI 응대 후 고정 휴대폰 전환): [설정과 실행](phone/CLAWOPS.md). 기존 SIP 테스트는 그대로 유지됩니다.
